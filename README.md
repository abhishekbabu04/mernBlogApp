# 📝 MERN Stack Blog App

A full-stack blog application built using the MERN stack. This project provides a platform for users to explore and manage blog content with a modern, responsive user interface.

## 🚀 Tech Stack

- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB

## ✨ Features

- Responsive and modern UI
- User authentication
- Create and manage blog posts
- Image upload and cloud storage
- Secure authentication
- REST API integration
- Database integration
- User-friendly notifications

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd MERN-Blog-App
```

### 2. Start the Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Start the Backend

Open another terminal:

```bash
cd backend
npm install
npm start
```

### 4. Environment Variables

Configure your MongoDB connection, authentication secret, Cloudinary credentials, and other required environment variables in the backend `.env` file.

**Important:** Never upload your `.env` file or secret credentials to GitHub.

## 🌐 Deployment

- Frontend: Vercel or Netlify
- Backend: Render
- Database: MongoDB Atlas
- Media Storage: Cloudinary
